# Лабораторная 8. Secure CI

Автор: Скляров Константин Александрович, группа РИМ-150975к.
Проект: https://github.com/dyda5505-cloud/textlab-course. Workflow: .github/workflows/security.yml.

Pipeline запускается при push и pull_request. Последовательные проверки:
pytest — автотесты, Bandit — статический анализ, pip-audit — уязвимости runtime-
зависимостей, Gitleaks — поиск секретов в полной истории Git с redaction.
pip-audit используется как проверка уязвимостей зависимостей; контейнеры не сканируются.
У job нет continue-on-error: любая проблема приводит к ошибке pipeline.
CI получает только contents: read; отдельные секреты для проверок не требуются.

Приложение использует параметризованный SQL, ограничение ввода и textContent
для отображения результатов; процессы контейнера работают от пользователя app.

Успешный запуск всех четырёх проверок: https://github.com/dyda5505-cloud/textlab-course/actions/runs/37193914423.
Bandit, Gitleaks и pip-audit завершились успешно, pytest прошёл.
Вывод: автоматические проверки безопасности встроены в проверку изменений
и не позволяют скрыть ошибку успешным итоговым статусом job.
